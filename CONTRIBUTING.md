# Contributing to LiberVoltis LV‑01

Thank you for your interest in contributing to LiberVoltis.  
This project is fully open‑hardware and community‑driven.

---

## 🧭 Contribution Workflow

1. Open an Issue describing your idea or problem  
2. Discuss the proposal with maintainers  
3. Create a feature branch  
4. Submit a Pull Request  
5. Wait for review and merge  

---

## 📐 CAD Guidelines

- Use metric units (mm)  
- Name files using `lv01_partname_vX.step`  
- Keep assemblies modular  
- Provide STEP + native CAD format  

---

## 🔌 Electronics Guidelines

- Use KiCad unless otherwise agreed  
- Include schematics, PCB, and PDF exports  
- Document all connectors and pinouts  
- Provide BOM inside `/bom`  

---

## 💻 Firmware Guidelines

- Keep code modular and documented  
- Include example configurations  
- Use clear naming conventions  
- Provide build instructions  

---

## 📚 Documentation Guidelines

- Use Markdown  
- Keep sections short and clear  
- Include photos or diagrams when possible  
- Update `/docs` when hardware changes  

---

## 🧪 Testing Guidelines

- Document test conditions  
- Include photos or videos  
- Provide raw data when possible  
- Add results to `/tests/reports`  

---

## 🤝 Code of Conduct

Be respectful, constructive and collaborative.  
We are building technology for people in difficult situations — treat the mission seriously.

---

Thank you for contributing to LiberVoltis.
